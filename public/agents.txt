# Why it stands out
standout:
  - The agent reads and writes the same analysis objects the interface shows, so an address it cites is real recovered data rather than text it produced on its own.
  - A rename lands in the listing, the call graph and the call sites at once, and survives restarts.
  - An integrated debugger, so a backtrace shares the listing's symbols and a stack trace is one click from the code.
  - Incremental indexing: a ten-thousand-function binary opens without a coffee break.
  - The engine is addressable, so runs can be repeated, forked, reset and compared rather than living in one unrepeatable session.
  - Analysis is local by default and the sample is not implicitly uploaded.
  - Apache-2.0 and auditable end to end.
